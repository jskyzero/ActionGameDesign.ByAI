## 一场「看着动画被画出来」的演示

GDC 2015 Animation Bootcamp 的开场环节，骷髅女孩主动画师 Mariel Cartwright 现场手绘，演示格斗游戏动画从零到一的全过程——不讲理论，而是「看它被画出来」。

### 骷髅女孩：每一帧都是手绘

- 游戏全部美术由传统动画师团队手绘，动画的**每一帧都是人工画出来的**。
- 不用骨骼驱动，换来「作画味」与自由度；代价是成本，所以流程与帧数都要精打细算。

### 动画怎么做：先可玩，再打磨

- **流程**：头脑风暴 → 快速草图 → 先做基础动画 → 交给策划放进游戏，达到可玩状态 → 反馈迭代 → 清稿 → 上色定稿。
- **帧数规则**：草稿阶段就按弱、中、强攻击定好总体帧数，与策划确认角色的动画需求后再精修。
- 角色在「简单动画」阶段就已经可玩，给美术留出充足的打磨时间。

### 演示中可见的动画要领

- **突出关键帧**：帧数有限，把力气花在关键姿势上，让动作「读得懂」。
- **动势强化**：残影与 overshoot 的一帧夸张，让出拳更有力量感。
- **打破骨骼限制**：为了动态效果可以画出「不可能」的姿势——动画的目的是创造运动，不是画一张完美的画。

> ✦ 一句话总结：手绘格斗动画的关键不是帧数多，而是流程上先让角色可玩、作画上把力气花在关键帧与动势上。
