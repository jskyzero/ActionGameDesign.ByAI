## 目标：用 3D 管线复刻 2D 格斗魅力

罪恶装备 Xrd 要在完全 3D 的工程里做出老式 2D 格斗的观感——关键不是「模型够不够还原」，而是「剪影与色调够不够 2D」。

### 以「2D 底稿」为基准建模

- 先画高品质 2D 设定稿，再让模型「照着画捏」——模型要抓住 2D 插画的剪影与比例，而不是写实人体结构。
- 头部与脸按原画建模：脸部是辨认的核心，先保「一眼认出是谁」，再谈细节。

### 赛璐璐式分层着色

- 用扁平色块取代渐变：把明暗、环境光压成有限的几层色码，逼近手绘动画的赛璐璐上色。
- 刻意避免 3D 常见的庞杂光影与边缘发光，压制「伪 3D」的观感。

### 轮廓线：只在关键处加黑线

- 沿剪影与局部色差处勾深色描边，模拟手绘的线条感；描边粗细随画面主观调整。
- 线条是「画风」的一部分，不是后处理的廉价滤镜——配合着色的色码统一设计。

### 玩法与演出

- 打击判定框由 3D 模型实时驱动，招式动作用 3D 动画直接演出，不再逐帧手绘。
- 必杀技转场等关键镜头保留立绘/2D 演出，3D 负责可动与镜头，两者互为补充。

> ✦ 一句话带走：2D 的味道来自剪影与扁平色调，而非模型细节——把「画风」做成可复用的 3D 工程规范。
