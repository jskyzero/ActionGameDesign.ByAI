## 立项背景：先想清楚「怪猎」是什么

《怪物猎人：世界》立项时，团队先回到初代宣传片，重新确认系列的根基，再决定「下一代」要怎么走。

### 系列的三大核心

- **动作**：怪物猎人首先是正宗的动作游戏，只是主题是狩猎。
- **多人 / 社交**：和朋友一起狩猎，把过程分享出去。
- **游戏循环**：狩猎 → 取材 → 做装备 → 挑战更强的怪物，这个循环是系列的骨架。

### 「下一代」的目标

- **受众更广**：不止日本市场，还要打动全球玩家。
- **无缝大地图**：一张连贯的大地图，狩猎要利用环境与生态。
- **先做故事版**：动手之前，用故事版把想要的场景和流程讲给团队听。

### 高层给的边界

- **辻本良三的两个要求**：为家用机做出「下一代」怪猎；让全世界的玩家都沉浸其中。
- **更少但更大的区域**：不做一堆小地图，而是把每张地图做得足够密，配上实时天气昼夜、怪物领地行为与互扰，形成活的生态。

## 原型一：让环境先「活」起来

第一版原型甚至没有战斗——先验证一件事：不靠怪物，世界能不能让人感觉是活的。

### 填充小型生物

- **蜘蛛与两栖鱼类**：还没放大型怪物时，用大量小型生物填满地图；踩破蜘蛛网蜘蛛会四散逃窜，树上的壁虎会被玩家惊走。
- **幽暗环境与探索感**：更暗的场景 + 视野限制 + 引导虫带路，探索的紧张感更强。

### 光源的教训

- **额外光源破坏探索感**：发现怪物的过程本身就有乐趣，玩家自制的发光道具会提前暴露目标；而且氛围灯光性价比低、技术上还和场景灯光冲突，最终正式版选择把场景光调亮。

### 不用武器的玩法

- **草丛隐藏与烟雾**：被小怪群包围时不用武器，靠草丛藏身、释放孢子制造烟雾脱身。
- **沿用至正式版**：这些「躲藏 → 逃脱」的思路大多保留到了成品里。

## 原型二：大型怪物的行为验证

环境立住之后，重点转向大型怪物——它们怎么移动、怎么被打、怎么与玩家和环境互动。

### 移动与 AI

- **开放区域的穿梭**：巨大怪物在场地中移动，会被树木阻挡、也能撞断树木。
- **AI 找路**：怪物要能自行判断可行路径与碰撞；旧引擎里多只怪物同场几乎必然卡死，让 AI 自然寻路是整个原型的关键突破。
- **复杂地形**：测试爬墙等移动方式，以及「在怪物能通过的前提下，通道最小能做到多窄」。

### 骑乘与倒地

- **更有动作性的骑乘**：怪物会撞击障碍物试图把玩家甩下来，玩家得选择合适的部位（头 / 尾）骑乘、消耗它的体力。
- **自动操作平衡难度**：操作门槛过高，就加入满足条件时自动执行的设计。
- **倒地后的生态**：大怪物被打倒，原本围观的小怪物会一拥而上攻击它——敌人也能成为帮手。

### 环境机关与战斗节奏

- **闪光弹与藤蔓**：受刺激会发光的虫子可以阻碍怪物追击、减缓速度；藤蔓的震动可以传导成「地震」。
- **投技与投射器**：怪物的捕食投技 + 玩家用投射器打落带气味的果实，用来摆脱撕咬——给偏长的 BOSS 战增加改变节奏的手段。
- **治疗与隐蔽**：不能再切地图吃药，要在怪物眼皮底下创造喘息的空档；怪物还会靠气味追踪玩家，躲藏变得更难。
- **场景破坏**：引导怪物攻击破坏水库等场景，既能帮玩家狩猎，也顺带验证了多人同步。
- **怪物互斗**：测试怪物之间的冲突，让生态成为玩家可以利用的战术。

## 复盘：原型是概念的翻译器

- **故事版与案例流程**：为了让整个团队理解构想，用「沼泽埋炸弹 → 引怪 → 树林藏身 → 引回沼泽触发机关」这类小故事来讲设计，而不是空谈概念。
- **原型先行**：概念 → 原型 → 实测 → 迭代，用实机原型验证技术上限与制作标准，再决定做不做。

> ✦ 一句话总结：先不急着做战斗——用不带武器的原型验证「无缝世界的探索感」，再用大型怪物的行为原型验证技术与生态，概念设计就在这一轮轮原型中落地。
