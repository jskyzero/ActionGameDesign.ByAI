## 🦿 待机姿势怎样帮助玩家读招？

- **为攻击留下变化。** 巨型蟹状敌人「ファンタズマラネア」若待机时就高举钳子，会提前消耗攻击姿势的辨识度。保持中性，再在攻击时抬钳，才能形成清晰区别。
- **先验证功能。** 临时动画要快速进入游戏，分别承担待机、攻击、受击的职责，再逐步精修。

## ⚔️ 漂亮的攻击为什么仍要改？

- **用实际闪避检验节奏。** 该敌人最初跳到空中停顿再下落，测试发现难以回避，遂调整升降节奏。
- **动画师参与战斗迭代。** 动作在实机中测试，与程序员直接协作修改；可玩性决定取舍。

## 💥 命中的回报由谁表现？

- **敌人的反应也是奖励。** 不同程度的受击让玩家感到攻击有效，并看到战胜敌人的可能。
- **配合具体招式。** 山口在 2014 年官方日志中展示：续作按主角攻击匹配更多敌人受击动作。只看主角演出，会漏掉敌人反应带来的反馈。
