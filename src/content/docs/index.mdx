欢迎来到动作游戏知识库。这里把散落在各处（GDC 演讲、视频分享、原创方法论）的动作游戏设计知识，整理成**结构化、可检索、AI 友好**的条目。

## 从哪开始

- **[思维导图](/mindmap)** —— 多维度可缩放的导图总览（章节 / 年份 / 标签）
- **[目录浏览](/tags)** —— 按章节分组浏览全部条目（与原文结构一致）
- **分享索引（GDC）** —— 左侧边栏按章节（Capcom / PlatinumGames / Santa Monica / FTG / 其他 / Nintendo / 非 GDC）浏览
- **设计者笔记** —— 原创方法论（动作游戏的本质 / SSS 方法 / DOTA2 机制设计）

## 设计约定

每个条目都是纯文本 Markdown + 结构化 frontmatter（见 [内容约定](https://github.com/jskyzero/GDC.ACT)），方便 AI 辅助整理与批量生成。
