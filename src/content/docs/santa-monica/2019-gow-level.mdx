> 石匠关卡是战斗、剧情、探索三者融合得最好的案例——控制好三者的关系，就能控制游戏节奏。

## 三大核心要素（方向先行）

2014 年，团队为新作重新寻找核心要素：游戏总监 Cory 召集关键成员，最终确定了**战斗、剧情、探索**三个支柱，并把目标计划书贴在咖啡机走道的护栏上给所有人「洗脑」。

- **战斗**：冒险围绕动作展开，竞技场、线性遭遇、特殊规则与 Boss 战均匀分布，控制节奏。
- **剧情**：用父子故事做出系列从未尝试过的剧情玩法——无镜头定格的过场、慢节奏闲聊场景、环境叙事。
- **探索**：从真实摄像头转到 3D 摄像头（「摄像头决定品类」），解谜 + 选择性战斗 + 连接到更大的区域（九界之湖）。
- **融合**：不是所有关卡都能三要素完美融合，但一开始就往融合方向做，更容易做出好关卡。

## 六条关卡设计原则

### 1. 聚焦核心要素

- 不能在一个游戏里做完所有事，只能把几件事做好——这些就是核心要素。
- 核心要素让团队聚焦、思维方向一致，也让游戏与众不同。

### 2. 为核心要素设计指标

- 指标 = 游戏玩法的设计衡量标准，是关卡设计的「砖块」。
- 团队有一份《关卡打造密码》：人物与场景下的具体标准（1 米 / 2 米 / 3 米），墙壁高度、通道宽度、障碍物厚度都有精确要求。
- **3 米是角色直接攀爬的上限**，不算太高，但足以造成「从一个关卡到另一个关卡」的感觉，成为战斗结束或探索秘密的奖励。
- 台阶高度、圆平台直径、跳跃间隙、斜坡都按指标定，让研发目标清晰、可做深度测试（如攀爬动画测试）。

### 3. 强调主题

- 每个关卡都讲述一个主题，主题成为关卡的基础；设计得当，很容易做出多样性和复杂场景。

### 4. 所有重要路径关卡都解锁一个新能力

- 每 90~120 分钟解锁一个新能力，让关卡与众不同、避免千篇一律。
- 阿特柔斯的电箭：学习过程刻意保持简单；最初设计是奎爷自己解谜，后改为让阿特柔斯帮忙，顺带升华父子感情。
- 新能力带出解谜、秘密空间与战斗变化——**电箭出现的地方往往意味着新的秘密**，也让玩家记住它。

### 5. 给玩家清晰的探索间歇

- 目标：玩家能自己判断「何时探索、何时推主线」，知道一段剧情要投入多久。
- 新能力解锁后进入**休息时间**让玩家练习；石匠关卡里电箭分布占关卡四分之三，剩余四分之一是 Boss 战的关键转折点，之后就是休息区。
- 用红色水晶等视觉标记引导自主探索（乘船时看到路边红色石头）；必要时用奎爷和儿子的对话反映玩家内心想法。

### 6. 用核心区域连接所有关卡

- **核心并非开放世界**——核心是能向外发散的中心化位置，像车轮的轴心。
- 九界之湖就是核心区域：在石匠关卡学到电箭 → 返回核心 → 去小地方练习 → 熟练后再探索主要关卡 → 学到新事物 → 回到核心，循环往复。

## 现实与取舍（隐藏的第七原则）

- 解谜很重要，但**不是核心要素**——这个结论花了 2 年半才确认。
- 3 米指标遇到灌木丛：环境团队把灌木丛设计成世界高度的边缘，即玩家不可通行之处。
- 并非所有关卡都强调主题、每个关卡都有新物品——都是为了增加多样性，后期关卡会把此前所有玩法叠加在同一个场景里。
- 九界之湖没有做正圆：正圆理论上完美，但会严重限制环境设计，最终做成了不规则形状。

> ✦ 一句话总结：三大核心要素定方向、指标定骨架、新能力与探索间歇定节奏、核心区域定结构——这套打法从概念到完成，任何规模的团队都能用。
