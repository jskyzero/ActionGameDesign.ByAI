# docs/prototype/ —— 设计原型（仅参考）

`home.html` 与 `article.html` 是站点早期的**视觉设计原型**，用于确定整体美术风格。现已实现到 `src/`（Astro 站点），本目录仅作设计参考保留，**不参与构建、不部署**。

| 文件 | 说明 |
|---|---|
| `article.html` | 文章详情页原型（封面 / 核心观点 / 信息卡 / point 卡片 / takeaway） |
| `home.html` | 首页原型（hero + 卡片流） |
| `refinement.html` | 原结构微调的可点击示意：原样式 / 微调对比、手机宽度、卡片与文章往返；待确认，不作为正式设计规范 |

## 用途

- 当需要「对标原型」调整视觉时，直接打开这两个文件对照即可（配色、圆角、字号、卡片结构都以这里为蓝本）。
- 设计 token 已沉淀到 `../../src/styles/tokens.css`；如果原型和实现在某处不一致，以**原型为准**回溯 token 或组件样式。

## 查看方式

直接用浏览器打开（无需构建）：

```bash
open docs/prototype/article.html   # macOS
# 或直接拖进浏览器
```

## 本轮交互示意

直接打开 `refinement.html`，无需启动站点。保留现有首页与文章的信息顺序，只提议加深次级文字、允许卡片标签换行、明确键盘焦点。样例内容取自现有文章，详情正文为占位说明；原样式为节选重绘，并非逐像素复刻。示意不加载网络字体，本机未安装文楷时使用系统字体。
