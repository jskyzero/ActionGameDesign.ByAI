背景布局：把画面当成一张画来排

レイアウト（布局）指在画面内配置多个要素、组合起来构筑画面——要素不只是树木、帐篷等物体，颜色与光（影的形状、雾的渐变）也算在内。

  • 本讲不讲关卡设计与概念艺术，专注 3D 图形部门如何用布局做出「印象强烈的背景」，案例覆盖 DLC《黄金树幽影》与新作《黑夜君临》。
  • 3D 图形部门认为布局质量由两点决定：消除单调与平衡视线引导——坏布局的问题都出在这两处。

提升布局质量：消除单调 + 平衡视线引导

坏布局的通病

  • 相同形状的重复：即使改了大小、做了镜像，看起来仍是同一图形排成一排。
  • 只用曲线构成：同质要素堆叠；动线若是直线，视线移动也随之单调。
  • 左右对称的配置：对称有「强印象」的优点（人工建筑也常不得不对称），但单调感必须靠其他要素弥补。
  • 明度・色相变化少：画面大部分区域颜色变化小——用马赛克看色相、转黑白看明度，问题一目了然。
  • 要素偏向一侧：如左侧堆满要素，视线就被拽向左边，而不是该去的方向。
  • 目的地融入环境：目标不醒目，视线无从被引导。

好布局的修正手法

  • 打破重复：减少重复数量；改变部件的朝向、比例、高度使其不规则，并把部件朝向对齐目的地，稳定视线引导。
  • 加直线：画面多是曲线时，在远景放直线光柱（ライトシャフト）——既打破单调，又把视线引向目的地。
  • S 字动线：把通向目的地的路线做成 S 形曲线，游戏中大量使用。
  • 非对称平衡：左右两侧都有要素但不完全对称，沿纵深交替偏移制造节奏。
  • 给目的地打光：提高地标明度，让它从环境中「浮出来」。
  • 静态审查：尽量不动相机、把画面当静止画检查——检查范围变小，问题更容易暴露；电影、摄影同理：同样的情境，布局决定画面质量。

强化印象：往画面里放「违和感」

  • 质量再高，连续出现也会审美疲劳——每个区域要有不同印象，且变化要配合世界观（变化过大会被否），并在整个游戏层面设计印象变化的节奏（与游戏设计联动）。
  • 核心手法：放入**「违和感」要素**——与周围「方向、性质不同」的东西，包括物体、颜色与光、要素朝向（矢量）、质感四类。
  • 违和感要素放在两处：地标（本来就是视线引导的目标，设计得与众不同反而合适）与画面的大面积（如大量同向直线，但要叠加不同朝向的直线防单调）。
  • 远景的天空可以单独用不同光照模型打光：近景远景同一光照会得到自然的白云，分开打光则得到现实中不存在的黄色天空——强化印象的常用招。

限制：不是每帧画面都值得精雕

  • 作业成本限制：布局手法成本高，不可能每个场景都做——集中资源到视点（ビューポイント）：设在情境切换的位置、相机朝向动线方向；玩家刚进入新情境时最注意风景，这里最值得投入。
  • 游戏要件限制：战斗舒适（房间与通道加大）、紧张感（足场收窄）、引导玩家去指定地点——布局必须让位于玩法。

案例：DLC《黄金树幽影》

按难度从低到高介绍三个区域——限制越少越自由，限制越多越考验手法。

青蓝海岸：纯视觉的自由发挥

  • 全 DLC 最梦幻的区域，没有游戏性限制 → 美术只管视觉，作业难度低。
  • 修正手法：直行动线掺入曲线；要素左右非对称、按组交互配置、墓碑石棺朝向不规则；画面中央放高要素把视线锁在中心。
  • 违和感要素 = 发光的花：普通花草是程序化自动生成，发光花承担布局功能，在视点处手动逐个放置，远景花田甚至用手绘贴图调密度与亮度。
  • 选蓝色的理由：相邻区域是「褪色的黄昏感」「沉重的暗紫」，蓝色一出现就是视觉新鲜感——被否的方案正是「与其他区域印象相似」的配色。

墓地平原：近景受限，远景填满

  • 玩家进入 DLC 的第一个区域，印象必须最强；游戏要件是「表现广大的原野」→ 近景禁止放地标以外的大部件。
  • 早期提案「近景种树」消除单调 → 因不满足要件被否；最后方案：往远景塞满要素抵消近景的空荡。
  • 修正：悬崖直线轮廓改复杂剪影；崖面加雾渐变 + 光柱（纵向与纵深双轴变色）；天空向地标方向变亮；概念艺术家把地标巨树重做成独特造型。
  • 还不够 → 给地标树加上横跨天际的巨大帷幔（ベール），用强烈的违和感「压住」前景空旷；被否的提案是窗帘式帷幔——印象强，但引导视线的作用弱。

幽影亚坛：复用资源的换色魔法

  • 两个硬要件：复用墓地平原的资源（内存与工时所限）+ 地标必须占画面极大比例（压迫感与沉浸感）。
  • 同资源 → 起初和墓地平原几乎一样、区域观感连续 → 靠换色解决：土黄色基调 + 黑色竖线作违和感（用减算处理避免融入雾中）。
  • 地标（城寨与更远处的巨树）大得装不进画面——干脆将计就计：只展示局部，玩家会主动移动相机补全全貌——目标是「近距离观赏巨大绘画」的体验；被否的方案是火焰感的红线（太花哨）。

案例：《黑夜君临》的 Boss 战场

Boss 战场是每个循环的终点，空间要求极端：所有 Boss 共用地形、极宽阔、无段差——不阻碍移动与攻击的任何动作；地形为缓坡与合理高低差，配置物不挡敌人（碰撞基本可无视）。

  • 后半战无过场无缝变化 → 切换时不能改变碰撞构成（突然出现带碰撞的岩石会卡住角色）→ Boss 战场基本只能靠「天空与地面」做文章。
  • 于是要在最强的限制下做出印象最强的画——三个案例。

三头兽：朝霞与幻影旗

  • 首个完成的后半战战场，之后成为所有 Boss 后半战的基准。
  • 先搭「天空 + 地形」的基本构成，印象优先于品质：熟悉的朝霞光照 + 现实见不到的异质天空作违和感。
  • 幻影旗像柱子一样排向地平线：制造左右信息差、把视线引向纵深；旗子与概念艺术家事先共享要件，设计成「没有碰撞也不违和」。
  • 地面爬行的火焰逆着视线引导的流向，反而成为强化印象的违和感。

吞噬之颚：天空之眼

  • 天空的巨大空洞唤起瞳孔联想，四周是剧烈撕咬的痕迹 → 强烈的中央视线诱导。
  • 黑色厚雾如云覆地，把地平线剪影改造成谷型——藏住单调的地平线，又表达异质感；雾剪影 + 天空构成「巨眼」。
  • 新要件：发光太刺眼妨碍战斗、配置物挡住敌人动作 → 压低发光 + 半透明化（能看见背后的敌人）+ 接地处加摇曳表达维持存在感。

暗夜猎手：黄金黎明与地面预兆

  • 「暗夜中的黄金黎明」意象，与前两例不同，是强化纵向信息的布局。
  • 光柱分组配置破除左右单调，云层明度色相变化补斜向信息，避免纵向单调。
  • 新要件：Boss 大量地面攻击 → 地面醒目物必须极少：拉大配置间隔、镜头前 shader 淡出处理（玩家靠近配置物即隐去）——脚边的攻击预兆始终清晰可见。

✦ 一句话总结：消除单调、平衡视线引导、放进违和感，再把资源集中在视点与限制的夹缝里——背景布局就是给世界留下「一眼难忘」的印象。
