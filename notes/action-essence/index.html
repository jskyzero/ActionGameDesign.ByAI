动作游戏的本质

🎯 奖惩导向⚙️ 底层机制🧩 MDA 理论
核心观点

「控制」本身并不有趣，让动作游戏有趣的是一套奖惩导向——设计考验场合、奖励正确、惩罚错误，玩家在「感知-认知-行动」的循环里越玩越强。

什么是动作游戏

动作游戏是歧义最大的游戏类型之一——先划清边界，再谈本质。

广义与狭义

  • 广义定义：任何以动作为主要表现内容的游戏都算动作游戏，MOBA 里的英雄技能、射击游戏里的近战动作，都是动作游戏跨类别的「影子」。
  • 狭义（日式）定义：2D 分横版卷轴、纵向卷轴、俯视角、固定画面；3D 分无双类、硬核动作、怪猎、魂 like；格斗类作为掌上明珠单独枚举。
  • 本文讨论的是狭义：强调「反应与操作」的细分类型的松散集合；从碰撞框与帧数判定、攻击-防御-投掷三角克制，到跳跃空战、群体战斗 AI、QTE、一闪——这些设计创举几乎都出自日式动作游戏，这张发展史本身就是一部动作游戏设计史。

本质的抽象

  • 核心逻辑：玩家 控制 游戏角色 播放 动作。动作游戏的一切设计，都由这一句底层抽象展开。

哲学与本质：奖惩导向

「控制」本身提供的乐趣是有限的，动作游戏靠什么让控制变得有趣？答案是赋予控制更多意义。

控制的乐趣

  • 纯控制乐趣有限：按游戏感理论，单纯控制主要提供「即时控制」与「润色（特殊物理感受）」两种感受。
  • 赋予控制意义：把控制放进「观察画面 → 获取信息 → 再控制」的循环里，乐趣就从操作本身转移到读懂考验、做出决策之上。
  • 动作游戏像音游：对高手玩家而言，一旦完全掌握决策规则与画面阅读，剩下的事情（抓时机、卡判定）和音游几乎没差别——这反向说明，大众玩家的乐趣不在「纯执行」，而在「破解考验」。

奖惩导向

  • 奖惩导向：玩家做出正确控制时给奖励、错误控制时给惩罚——最基本也最广泛的例子是血量。
  • 与白金工作室呼应：2016 GDC《无国界的动作游戏》说动作游戏是「根据情形选择行为的被动游戏」，设计动作游戏就是「设计考验场合，以及突破考验场合的方法」——同一套思路。
  • 与樱井政博呼应：2004 GDC《游戏设计：风险与回报》早已把奖惩思路用于一般玩家行为的反馈设计——它不局限于动作游戏。
  • 旗舰评论：狭义动作游戏的历史，就是想尽办法设计玩家可判读的资讯，然后奖励正确操作、惩罚错误操作。

奖惩导向怎么落地

奖惩导向要生效，有前提条件，也有方向取舍与长期有效性的问题。

奖惩生效的三个环节

  • 获取信息：动作与画面清晰明确；位移、判定符合预期，且有经验可循。
  • 采取行动：玩家有应对各种情况的处理方式，且知道这些方式存在、知道如何选择。
  • 行动产生结果：结果呈现清晰、明确、自然。反向例子：动画看不清 → 信息获取失败 → 决策失据 → 结果不符预期，体验随之崩坏。

方向取舍：场合与选项

  • 场合少、选项多：无双类——主角性能强、可操控角色多，怪物考核弱。
  • 场合多、选项少：魂 like——主角能力种类少，关卡与敌人的丰富度和考核方式极多。
  • 两者均衡：不要贪心——「左手画圆、右手画框」很难；都想做就降低各自难度，或至少循序渐进地提高。

让奖惩长期有效

  • 避免奖励同质化：受击僵直可以做成不同的连招序列；控制方式可分浮空、投技、眩晕；不同怪物可以有不同僵直甚至霸体。
  • 让收益最大化有门槛：靠操作难度，或靠玩家自行探索发现——奖励要「够得着但不白给」。
  • 动作游戏天生有深度：行为即时响应、高耦合、多重状态变化（攻击常伴随位移），门槛与复杂度写在底层基因里。
  • 结论：奖惩导向是否有效、有趣，直接决定一款动作游戏的耐玩性与乐趣度。
  • 奖惩 vs 交互：奖惩判定是某个静态瞬间的「交互结果描述」；奖惩导向是玩家「选择交互方式」的过程——后者才是设计要管的。

基于 M-D-A 的拆解

把「玩家控制角色播放动作」放进 机制-动态-美学（M-D-A）框架，可以拆出动作游戏设计的三个层次。

动作游戏的两种乐趣

  • 控制感：符合直觉的控制、丰富的控制选项、丰富的考核场景（带来不同的正面应对意义）。
  • 打击感：聚焦动作本身的美学呈现。

底层机制

  • 状态机：决定动画状态的数量、长度、表现与跳转——如一个 Actor 有 idle / walk / show 三个状态。
  • 逻辑轴：决定单个动画的框体变化、逻辑脚本执行、表现创建——如 walk 状态带受击框。
  • 系统规则：更上层的规则，如数值积蓄——如攒满 3 格能量才能从 idle 跳转释放技能。
  • 典型实现：攻击命中进受击动画（攻击框与受击框相交）、投技（投技框与受击框相交）……
  • 模糊机制的代价：动画融合过多导致帧数感知不清、判定与移动引入辅助算法弱化性能感知、打断规则不清晰、预输入规则不统一——未必是致命缺陷，但决定一款动作游戏能否达到殿堂级「高度」。

微观循环：感知-认知-行动

玩家每一秒都在重复 感知 → 认知 → 行动 的循环；感知的目的是利用奖惩机制让控制更有乐趣。

  • 针对感知：引入信息传递模型（发送、噪声、接收），每个环节都能对应具体设计。
  • 针对认知：玩家的决策规则应与设计师的规则保持一致，奖惩才持续有效。典型的认知行为目标：
    • 精准交互类（感知）：配合敌方动作判定释放动作，换取额外效果——当身、返技、弹反、防反、GP。
    • 抉择类（认知）：结合敌我位置与状态，从可选行为中选出最优。
    • 量表计算类（认知）：统计攻击量表的增减，利用满额效果（如硬直）。
    • 移动-回避类（行动）：远离攻击区域。
    • 移动-进攻类（行动）：精确调整位置与朝向，让下一次行为刚好命中目标或特定部位。
    • 连招 / Combo（行动）：在僵直窗口内连续完成指令输入，可能需要摇杆组合按键——搓招。

行动与注意事项

  • 输入设备：屏幕、键鼠、手柄各有经典的输入模式设计。
  • 别要求「左手画圆、右手画框」：既要精准阅读信息即时操作、又要复杂输入高精度瞄准，多半是为难玩家——同时要求做多件事，是设计师最常忘记、也最容易被玩家骂的事。

打击感

  • 三个部分：攻击动作（开始、攻击、结束）、攻击特效、受击动作——话题太大，这里只点出框架。

从微观到宏观

微观循环是动作游戏的「帧」，玩家真正玩到的，是由无数帧组织起来的内容序列。

  • 层级递进：离散的画面组成电影，离散的动作组成角色，离散的角色（作为敌人）组成关卡，关卡构成游戏。

内容构建理论与工具

  • 体验蓝图与玩家阶段：控制玩家是否处于心流区间，是构建复杂体验的常见方式。
  • 叙事与英雄之旅：PVE 游戏的主角与怪物离不开关卡与叙事；让动作设计贴合经典叙事结构（如英雄之旅），整体更容易被接受、印象更深刻。

✦ 一句话总结：动作游戏的本质是「玩家控制角色播放动作」；让控制有趣的钥匙是奖惩导向——设计考验场合、奖励正确惩罚错误，再把「感知-认知-行动」的微观循环，一路编排进从底层机制到关卡与叙事的宏观结构。
